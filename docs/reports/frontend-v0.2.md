# Frontend v0.2 — 메인 페이지

2026-11-08 KST. v0.1 공통 JSP와 설정을 보존하고 메인 화면을 구현했다.

- 4열 모자이크 전시, 중앙 2×2 캐러셀, 이전·다음·자동 재생/정지, 카테고리 바로가기 10개, 캠페인 띠, 6열 추천 상품 2개 섹션을 추가했다.
- `shop-ui.js`의 공통 상품 카드, `mock-repository.js`의 JSON 공급, `storefront.js`의 메인 구성, `commerce.css`를 분리했다. 상품 이미지 비율은 3:4다.
- 초기 상품 14개 중 이름·가격·분류를 문서에서 확인한 표본 2개와 임의 생성 상품 12개를 구분했다. 사진 대신 자체 제작 SVG 6개를 사용한다. 관찰 표본도 재고·평점·이미지는 Mock이다.
- Tomcat 9 / Java 11 / Chrome headless에서 1440·1280·390px로 검증했다. 캐러셀 다음·이전·정지, 12개 카드 출력, 카테고리 Hover/Tap과 ESC·초점 복귀, 공통 레이아웃 재사용이 통과했다. 콘솔 오류와 문서 가로 넘침은 없었다.
- 결과: [v0.2-results.json](frontend-commerce-evidence/v0.2-results.json). 캡처는 같은 폴더의 `v0.2-home-{1440,1280,390}.png`다.
- 이 단계의 바로가기는 메인 전시 앵커로 연결하고 상품 탐색은 v0.3에서 연결한다. 외부 배너·사진·원본 문구를 그대로 복제하지 않아 실제 사이트와 디자인이 다르다. 실물 모바일·Safari·스크린리더·Eclipse Publish는 미검증이다.

검증 통과 후 승인 대기 없이 v0.3으로 진행했다. Commit·Push, DB, Maven·Gradle은 사용하지 않았다.
