# Frontend v0.3 — 상품 탐색

2026-11-08 KST. 공통 목록·상세·검색 화면을 구현했다.

- `list.jsp`, `search.jsp`, `product.jsp`는 고정 페이지 키를 설정하고 WEB-INF의 공통 `page.jsp`로 Forward한다. 상품마다 JSP를 생성하지 않는다.
- `catalog.js`가 목록·상세를 구성하고 Repository의 카테고리 하위 트리·검색·정렬·가격·구매 가능 조건을 조회한다. 필터 상태는 URL에 유지하고 30개 단위 더 보기를 제공한다.
- 검색창, 메인 상품 카드, 카테고리 바로가기와 최하위 메뉴를 프로젝트 내부 URL로 연결했다. PC Hover는 탐색만 유지하고, 모바일 중간 분류 Tap은 하위 열을 연다.
- 상세는 분류 경로, 이미지, 가격, 출처, 상태·재고, 수량·합계, 배송비 안내와 설명을 표시한다. 장바구니는 v0.6에서 연결한다.
- Java 11 / Tomcat 9, Chrome headless의 1440·1280·390px에서 검색 → 상세, 수량 합계, 가격 정렬·필터, 검색 결과 없음, 잘못된 상품·분류 ID, 카테고리 → 목록 이동 및 공통 회귀 검증이 통과했다. 콘솔 오류·문서 가로 넘침 없음.
- [실제 결과](frontend-commerce-evidence/v0.3-results.json). 목록·상세·홈 캡처는 같은 폴더의 `v0.3-*.png`다.
- 실제 사이트의 가상 스크롤은 단순 더 보기로 대체했다. 배송 유형·브랜드 세부 필터·리뷰·옵션·실제 상품 고시·실물 모바일은 구현 또는 검증 범위 밖이다. 데이터는 이 단계에서 14개이며 전수 카테고리 보강은 다음 단계다.

검증 후 v0.4로 진행한다. 기존 카테고리 원본과 프로젝트 설정은 보존했다.
