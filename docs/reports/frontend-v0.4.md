# Frontend v0.4 — 카테고리별 상품 데이터

2026-11-08 KST. `node tools/build-products.cjs --all-leaves`로 730개 최하위 분류 각각에 대표 생성 상품 1개를 제공했다. 기존 관찰 표본 2개를 더해 총 732개다.

- 원본 871개 분류 JSON은 변경하지 않았다. SHA-256 `35610B03FBC6BA5543E2904CF9B49EBE5B70DF6B686FC8FB40A673A2E8DC1CAC` 동일.
- 상품 ID는 내부 `MOCK-카테고리ID`, 관찰 표본은 `REF-품번`이다. 실제 사이트의 상품 ID라고 주장하지 않는다. `categoryId`, 가격·상태·온라인/매장 재고, 이미지·설명, 생성일·정렬값과 `source`를 가진다.
- `source.kind=GENERATED`는 임의 생성 730개, `REFERENCE`는 Aside 문서에서 이름·가격·분류만 확인한 2개다. 표본의 이미지·재고·평점 등도 Mock임을 카드와 상세에서 알린다.
- 730개 분류 전체 커버리지, 상품 ID 732개 고유성, 모든 상품의 유효한 최하위 부모 ID를 전수 검사했다. 중분류 종료 2개 경로도 포함한다.
- Java 11 / Tomcat 9에서 1440·1280·390px 홈·목록·상세·검색·필터·카테고리 이동·공통 컴포넌트 회귀 검증이 통과했다. 품절·판매예정 상세의 담기 비활성도 확인했다. 콘솔 오류와 가로 넘침 없음.
